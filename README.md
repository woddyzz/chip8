# CHIP-8 Emulator in C

A CHIP-8 emulator written in **C**, built from scratch to understand how low-level systems work. Runs classic CHIP-8 games accurately by emulating the original CPU, memory, timers, input, and graphics.

## Features
- Implements the full CHIP-8 instruction set  
- Fetch–decode–execute CPU loop  
- 4KB memory with ROM loading  
- 16 general-purpose registers, stack, and program counter  
- Delay and sound timers  
- 64×32 monochrome display  
- Keyboard input handling  

## What I Learned
- How a CPU fetches, decodes, and executes instructions  
- Bitwise operations and memory management in C  
- Stack and subroutine behavior  
- Timer implementation and synchronization  
- Debugging and structuring larger C projects  

## Purpose
This project was a hands-on way to learn **systems programming**, **computer architecture**, and **emulation fundamentals**. It also serves as a foundation for building more advanced emulators or game engines.
